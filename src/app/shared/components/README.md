# Shared — Components

Component ที่ใช้ร่วมกันหลายโมดูล

| Component | Description |
|-----------|-------------|
| `navbar/` | แถบนำทางด้านบน |
| `sidebar/` | เมนูด้านข้าง + mobile drawer |
| `footer/` | ส่วนท้าย |
| `breadcrumb/` | แสดงเส้นทางนำทาง |
| `loading/` | ตัวแสดงสถานะโหลด/สปินเนอร์ |
| `pagination/` | แบ่งหน้า |
| `status-badge/` | Badge แสดงสถานะ |
| `tabler-icon/` | Wrapper Tabler SVG Icons |
